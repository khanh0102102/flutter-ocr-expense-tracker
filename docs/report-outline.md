# Technical Report Outline

Use the official 2–4 page course template.

1. Project summary and problem statement.
2. Feature checklist.
3. Architecture diagram and data flow.
4. Screenshots: dashboard, camera, OCR review, expense list and charts.
5. Technical notes: on-device OCR, regex heuristics, integer VND, SQLite indexes, image cache and CustomPainter.
6. Testing and release workflow.
7. Conclusion and limitations.

The report should explicitly state that OCR is local/on-device and that users verify extracted values before saving.
